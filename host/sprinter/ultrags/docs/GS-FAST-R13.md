## Результат R12/D3

На фото 2026-10-20 23:11:36 все 16 строк UGGS0 показывают:

```text
STATUS=01 ERROR=00 GSERR=00 NATIVE=7E ALIAS=FF AFTER=7E
```

Владелец подтвердил отсутствие перезапуска после GSALIAS ON.
Все чтения D3 выполняет при программно выключенном Turbo. Native 02BB
отвечает нормально до и после чтения алиаса 00BB; причина не ограничивается
Turbo в PROPLAY. Это также не наблюдение двух занятых GS-флагов:
соседние native-чтения показывают idle. Электрический механизм не измерен.

В R12 низкий алиас проходит через программный decode/WAIT и
ug_minimal_read_decoded. До получения GS STATUS этот диспетчер вызывает
ug_stat_add: атомарный compare/exchange на RP2040 использует SDK spinlock.
Счётчик, блокировка и общий switch не нужны для подготовки байта статуса.
Native 02BB идёт через ранний PIO WAIT, поэтому физические пути различаются.
Это конкретная устранимая задержка, но её достаточность для объяснения
каждого FF должна быть проверена на карте.

## Изменение

Опция UG_GS_STATUS_FAST требует COMPAT/HANDSHAKE + CONFIG_CATALOG_FAST,
без TRACE/PROBE. Только включённый алиас **ровно 00BBh** получает короткую
ветку до общего native decode: IO_WAIT → живое атомарное чтение GS-флагов →
байт в FIFO → статистика. Никакого постоянного ответа 7E: занятые CB/DB
по-прежнему дают 7F/FE/FF.

Проверка живого /IOR и совпадения адреса остаётся перед веткой.
При GSALIAS OFF и на соседних портах ответа нет. PIO, его память 10+22,
fuse, CONFIG R12, native, GS DATA/COMMAND и Settings не меняются.
Изменение не заявляет готовность legacy LOAD или звука.

## Проверки

- Две независимые MULTIFW сборки побайтно совпадают; linked-проверка
  подтверждает R13 identity, COMPAT и PIO10+22, сохранённый fuse.
- Исполнение linked ARM: четыре состояния флагов в обеих сборках,

  при 16 искусственно занятых чтениях lock — 118. Это не полное время

## Проверка на карте

После записи CURRENT.UF2 обычным способом запустить:

```text
UGCFG ULTRAGS /GSALIAS ON
UGCFG INFO
UGGS0
```

INFO должен показать `pg-ultrags-gsfast-r13 v4.1.1`, GS ON.
В UGGS0 ожидаются 16 строк с NATIVE=7E ALIAS=7E AFTER=7E.
Если остался FF, остановиться и прислать полный вывод.
Только после успешной пробы:

```text
PROPLAY C:\MEDIA\MODS\ATDT.MOD
```

Прислать результат обнаружения/загрузки и отметить, есть ли нормальная
музыка без хрипа и обрывов. Основные EXE D2 и пробы D3 прежние.
Старая рабочая R12 сохранена в build/config-fast12-delivery/CURRENT.UF2.
Не использовать USB одновременно с питанием Sprinter для этой платы.
