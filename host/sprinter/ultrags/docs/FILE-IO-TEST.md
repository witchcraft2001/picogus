# UGDUMP и ускорение файловой передачи, 2026-10-19

Постоянный каталог: `build/latest/`. Для этой правки скопировать только
UGLOAD.EXE, UGDUMP.EXE и UGPLAY.EXE из ug-host.zip. Прошивка прежняя:
SHA256 f5b24f9cd92d38e7ee0b75294fae0c0dc3fd52271adcdf4d825811573bf13cea.

## Исправление записи DSS

DSS WRITE может изменить DE при записи таблицы FAT после данных. Старый
UGDUMP принимал DE за количество записанных байтов и мог завершиться FILE_IO
после первого блока 1024 байта. Новый вариант измеряет изменение 32-битной
позиции файла через SEEK current+0 до/после WRITE. Короткие записи завершаются
без повтора уже записанных байтов; нулевой, обратный или избыточный сдвиг и
ошибки DSS прерывают операцию. Неполный файл сохраняется. Диагностика FILE_IO
показывает dss_fn, a, flags до закрытия файла.

## Ускорение

Только файловые UGLOAD/UGDUMP/UGPLAY используют BULK окна до 256 байт вместо
8. Контрольные кадры, UGMEM и публичный default библиотеки остаются cap8.
Все ISA-чтения и записи по-прежнему при Turbo off, последовательность
2→ISA→3, восстановление PAGE3/IFF и ограниченная отмена сохранены. Размер
протокольного блока 1024 байта и алгоритм CRC не менялись. Длинные окна ранее
проходили физический 8-МиБ UGMEM; именно файловые EXE требуют нового REAL.

## Короткая проверка без перепрошивки

M заменить числовым handle MOD. Не использовать буквальное M.
Старый BACK.MOD не перезаписывать: новое имя BACK2.MOD должно отсутствовать.

```text
UGDUMP M BACK2.MOD /VERIFY
UGMEM INFO
```

Ожидается PASS, размер BACK2.MOD 448248, host_crc=0x11C38894 для вашего
ATDT.MOD. /VERIFY проверяет обмен с картой; дополнительно сравнить выгруженный
файл с оригиналом на ПК (SHA256
 a91378987b0c7f64676302645a9e7f1d5cb7fbf6398ad4d0a0f8e03ba27675f2).
Внешний файл владельца не входит в поставку.

Для сравнения загрузки остановить музыку/FX и освободить используемые объекты
обычными UGPLAY STOP, UGPLAY FXSTOP ALL, UGMEM FREE <handle>, затем выполнить
ту же команду, которая ранее заняла 22 секунды:

```text
UGLOAD ATDT.MOD /TYPE:MOD /CRC:11C38894
```

/CRC проверяет весь загруженный файл на карте при SEAL. Сравнивать скорость
при одинаковых параметрах: /VERIFY дополнительно читает файл и объект обратно.
Сохранить host_seconds и bytes_per_second. Затем повторить MOD + два stereo
FX по AUDIO.TXT с фоновым обменом и снять UGMON: underruns=0, audio_error=0,
psram_errors=0, без хрипа/звона. Третий stereo FX даёт ожидаемый NO_VOICE.
SAVE и длинный 8-МиБ тест повторять не нужно. REAL_PENDING, S6/S7 IN_PROGRESS.
