# UGTEST: исправление разбора команд, 2026-10-19

Постоянный каталог последнего проверенного комплекта: `build/latest/`.
В этой поставке требуется заменить только `UGTEST.EXE` на Sprinter.
UF2, UGCFG и UGMEM не меняются; перепрошивать карту не требуется.

В старом UGTEST начальные пробелы/табуляция и опции перед PCM/FX/PROTO
могли направить команду в парсер BUS и дать SYNTAX до обращения к карте.
Исправлен ограниченный длиной строки выбор парсера по полным словам.
Это воспроизведённая программная причина такого сообщения; совпадение
с установленной у пользователя версией уточняется по справке/повтору.

После копирования UGTEST.EXE, при активной ULTRAGS и без запущенного звука:

```text
UGTEST /?
UGTEST PCM
UGTEST FX
UGMEM INFO
```

Ожидается справка с PCM/FX, затем RESULT PASS code=0. В конце память
свободна, objects=0. При ошибке сфотографировать полный вывод и справку.
Для второго слота добавлять `/SLOT:1` ко всем командам.

PCM/FX проверяют операции API и освобождение временных объектов; PASS
этих тестов сам по себе не доказывает качество звука или отсутствие underrun
под нагрузкой. Общая аппаратная приёмка REAL_PENDING; S7 IN_PROGRESS.
