# D3: PROPLAY не обнаруживает GS при GSALIAS ON

Фото 2026-10-20 22:48:02: `UGCFG GSALIAS ON` и `UGCFG INFO` PASS,
прошивка `pg-ultrags-cfgfast-r12 v4.1.1`, ULTRAGS active/selected,
boot_state READY, BASE 02A0, BULK alias OFF, GS (00B3/00BB) ON.
PROPLAY v0.5.91 сообщает `General Sound not found.` Это REAL_FAIL
обнаружения GS; загрузка MOD и звук не проверены.

## Что установлено

Дизассемблирование исходного пользовательского EXE (§8.5 ТЗ):
в процедуре 8204h плеер читает 00BBh один раз в slot0, затем при FF —
один раз в slot1. Оба FF дают «not found» до reset F3, LOAD и PLAY.
Поэтому отказ ещё не свидетельствует о проблеме разбора MOD или аудио.

PROPLAY не переключает Turbo при открытии ISA. Наши UG-утилиты выключают
его на каждом ISA-окне. Функциональный LegacyMachine допускает такой
доступ, но не моделирует срок выдачи данных PIO/ARM. Прежний HOST PASS
не подтверждал совместимость на физической шине при Turbo ON.
Реальное состояние Turbo на фото неизвестно.

В R12 native 02BB получает ранний WAIT PIO, а 00BB использует программный
decode/WAIT и общий ug_minimal_read_decoded. Возможна зависимость от
задержки ответа. Это гипотеза, а не измеренная причина.
Также 7E OR CB OR DB может законно дать FF при двух занятых флагах.
Успешное включение алиасов требует GS idle, но состояние позднее нужно
проверить отдельно.

## Проверка без перепрошивки

В текущем ULTRAGS, BASE 02A0 и уже включённом GSALIAS:

```text
UGGS0
```

Взять UGGS0.EXE из `build/latest/CURRENT.ZIP`; для известного slot1 —
UGGS1. Проба делает 16 серий чтений STATUS, ERROR, GSERR, native GS STATUS,
alias GS STATUS и повторного native GS STATUS. Все ISA-чтения выполняются
при Turbo OFF; никаких записей в карту, reset, SAVE или consuming reads.
Ожидаем на простаивающей карте:

```text
STATUS=01 ERROR=00 GSERR=00 NATIVE=7E ALIAS=7E AFTER=7E
```

Прислать весь вывод. NATIVE=7E / ALIAS=FF / AFTER=7E выделяет отказ
низкого алиаса в этой серии; три FF не различают занятые флаги и потери
чтения. Различающиеся ответы могут также отражать смену состояния между
чтениями. Даже полный успех пробы не проверяет PROPLAY при Turbo ON.

Если доступно аппаратное отключение Turbo, отдельно повторить неизменённый
`PROPLAY C:\MEDIA\MODS\ATDT.MOD` при Turbo OFF.
Проба сама не оставляет программный Turbo выключенным после завершения.

UF2 R12 и девять основных EXE D2 сохранены побайтно; прошивать ничего не нужно.
Замороженная поставка: `build/gs-probe-d3-delivery`. Это диагностический
комплект, исправление прошивки по одному FF не объявляется.
S6/S7 IN_PROGRESS, GS detection REAL_FAIL / причина уточняется.

## Программные проверки D3

Две независимые сборки UGGS0/UGGS1 побайтно совпадают.
96 actual-EXE сценариев проверяют точный порядок 96 чтений, отсутствие
записей в карту, Turbo OFF на ISA, восстановление PAGE3/IFF/SP и ограничение
времени окна. Проверены idle, FF, занятые/меняющиеся флаги и ошибки.
Четыре прогона с production C подтверждают alias ON/OFF в обоих слотах.
Ещё четыре запуска исходной процедуры обнаружения PROPLAY подтверждают
ветки 7E/FF и отсутствие переключения Turbo при обоих начальных режимах.
Это проверка логики EXE, не моделирование электрических задержек.
UF2/основные EXE сверены с D2, содержимое ZIP/IMG прочитано обратно.
