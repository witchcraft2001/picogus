# D4: GS STATUS при программном Turbo OFF / ON / OFF

## Аппаратный результат R13, 23:43:13

UGGS0: все 16 строк STATUS01/ERROR00/GSERR00 и NATIVE7E/ALIAS7E/AFTER7E.
Это **REAL_PASS чтения idle GS STATUS через алиас при Turbo OFF**.
Затем PROPLAY v0.5.91 снова сообщает General Sound not found:
обнаружение GS плеером остаётся REAL_FAIL; загрузка и звук не проверены.
Версия firmware в кадре отсутствует; привязка к R13 — по контексту выданного
комплекта. Электрические задержки не измерялись.

PROPLAY не переключает Turbo при открытии ISA; UGGS0 выключает его.
Это различие требует проверки до следующего изменения PIO/прошивки.

## Проба

**Без перепрошивки.** Скопировать UGGSC0.EXE из CURRENT.ZIP.
При текущем ULTRAGS и включённом GSALIAS:

```text
UGGSC0
```

Для известного slot1 — UGGSC1. Не сканирует чужие слоты.
Проба делает 16 серий из трёх чтений **только 00BBh**, используя ту же
инструкцию `LD A,(C0BBh)`, что обнаружение PROPLAY:

- SLOW1: запрос программного Turbo OFF;
- FAST: запрос программного Turbo ON;
- SLOW2: повтор с Turbo OFF.

Это отдельная read-only диагностика с намеренным Turbo ON, не изменение
контракта основной ISA-библиотеки. Turbo меняется до открытия ISA,
а после закрытия возвращается штатный DSS Turbo ON. PAGE3/IFF сохранены;
никаких записей в карту, чтения DATA, RESET, SAVE или включения алиасов.
Каждое окно содержит одно чтение. Частота физически не измеряется:
аппаратный запрет Turbo может оставить все три чтения медленными.

При SLOW1=7E / FAST=FF / SLOW2=7E отказ зависит от программного режима
Turbo в этой пробе. Это не измерение IOCHRDY и не полное воспроизведение
длинной задержки/всей последовательности PROPLAY.
Три 7E требуют дальнейшего сравнения с условиями плеера, а не объявления
всего GS исправным. Прислать полный вывод.

UF2 R13, девять основных EXE D2 и пробы D3 не изменены.
S6/S7 IN_PROGRESS; аппаратный результат D4 REAL_PENDING.

## Проверки и поставка

Две независимые сборки обоих EXE побайтно совпадают. HOST_PASS:
128 actual-EXE сценариев (оба слота, IFF, начальный Turbo, аппаратное
разрешение Turbo, idle/отказ быстрого чтения/отсутствующая карта/живые флаги);
8 actual-EXE проверок с production C GS, aliases ON/OFF.
В каждом запуске ровно 48 чтений 00BB, ни одной записи в карту.
Проверены порядок переключений, PAGE3/IFF/SP, закрытие ISA и возврат Turbo ON.
Максимум окна модели 23,15 мкс, DI 105,72 мкс; это не измерения на Sprinter.
Функциональная модель не проверяет электрическое время ответа.

`build/gs-clock-d4-delivery/D4.json` содержит хэши и отчёты.
ZIP/IMG проверены обратным чтением; UF2 и все прежние EXE совпадают с R13.
Текущие файлы доступны через `build/latest`; перепрошивка не нужна.
