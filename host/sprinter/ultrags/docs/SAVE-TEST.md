# UGCFG: подтверждение SAVE, 2026-10-19

Холодный старт после ошибки SAVE_UNCONFIRMED подтвердил фактическое сохранение
ULTRAGS: active=desired=08, boot_result=00, READY, INFO и память PASS.
Повторять длительный ROUNDTRIP не нужно. Рабочая f5 UF2 остаётся установленной.

Новое UGCFG повторяет только чтение не потребляющего CFG_RESULT78 при FF,
с deadline/ESC/fallback. Команды SAVE/MODE/REBOOT и consuming reads не повторяются.
Успех требует наблюдать BUSY5 и затем OK0. Если вся BUSY-фаза потеряна,
показывается SAVE_UNCONFIRMED: успешная запись без полученного подтверждения
не выдаётся за проверенное завершение. Причина FF аппаратно не локализована.

Скопировать UGCFG.EXE из нового ZIP/IMG. Другие EXE и прошивку менять не нужно.
Для проверки исправленного подтверждения в новой сессии:

```text
UGCFG VERIFY
UGCFG SAVE /DIAG
```

SAVE запускать один раз и только после VERIFY/PASS. Для второго слота добавить
`/SLOT:1` к обеим командам. Сфотографировать полный вывод SAVE, включая
`stage/save_seen/started` и `save_result_ff_reads` (hex). Успех — сообщение
завершения сохранения и RESULT PASS. При FAIL сохранить `UGCFG INFO /DIAG`
и не повторять SAVE автоматически. При желании оставить уже подтверждённые
настройки без дополнительной записи этот тест можно отложить.

При PASS полностью выключить питание Sprinter/PicoGUS, включить, выполнить:

```text
UGCFG
UGCFG VERIFY
UGMEM INFO
UGCFG GUS
UGCFG
```

Первые INFO/VERIFY подтверждают ULTRAGS, последняя команда — активный GUS.
SAVE не нужен при возврате в GUS для этой проверки. Фактический SAVE и
холодный старт старой версии уже подтверждены; новое подтверждение SAVE,
остальные нагрузочные/электрические gates пока REAL_PENDING, S7 IN_PROGRESS.
