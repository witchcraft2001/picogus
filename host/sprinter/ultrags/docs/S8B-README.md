# S8b: FLT8, FLT4 и MOD до32 каналов — проверка на Sprinter

Gidion Graveland: исправлен излишне строгий FORMAT на исходном файле.
Физические пары из хвоста order table по-прежнему определяют начало samples;
номера инструментов проверяются в паттернах активной последовательности.
Неиспользуемые паттерны могут содержать произвольные данные. Это не меняет
исходный файл и не ослабляет проверки границ, размеров samples и loops.
Для DSS скопировать оригинальный gidion_graveland.mod под именем GIDION.MOD:

    UGPLAY GIDION.MOD /WAIT /VERIFY
    UGMEM FREE <напечатанный handle>
    UGPLAY GIDION.MOD /GS /VERIFY
    UGPLAY STOP
    UGMEM FREE <напечатанный handle>

Проверить все три позиции и возврат DSS. GIDION.MOD не включён в комплект.

UGPLAY FLT8TAIL.MOD /WAIT /VERIFY; затем освободить напечатанный handle.

Основа — COMPAT R17. Владелец подтвердил UGGSC, UGGST и PROPLAY при Turbo ON;

Скопировать EXE и FLT8.MOD из CURRENT.ZIP либо CURRENT.IMG на диск DSS.
ZIP не содержит UF2/IMG; прошивка выдаётся отдельно. Сначала выбрать ULTRAGS:

    UGCFG ULTRAGS
    UGTEST FLT8
    UGTEST FLT8 /VERIFY
    UGPLAY FLT8.MOD /WAIT

Для второго установленного слота добавить /SLOT:1; слот по умолчанию — 0.
UGTEST требует свободный foreground и отсутствие FX; загруженные чужие объекты
сохраняет. /RESET, /SECONDS и /VOICES для FLT8 не поддерживаются. Тест создаёт
собственный модуль частями, проверяет восемь разных периодов, переходы всех
шести orders через строки63, pause/resume и полный readback после playback,
затем освобождает только собственный объект. ESC прерывает с cleanup.
RESULT PASS code=0 должен сопровождаться возвратом к приглашению DSS.

FLT8.MOD — синтетический PCM-модуль: три пары четырёхканальных блоков,
orders 0,1,2,3,4,5 (попарно один логический паттерн). В каждом из восьми
каналов отдельный инструмент/период; каналы4..7 отличаются от0..3.
Периоды снижаются при переходах к следующей паре; row63 отличается от row0.
Файл играет около46 секунд; /WAIT возвращает управление после EOF.
Прослушать весь файл: обе половины должны звучать различимо, переходы между
парами должны быть слышны, после EOF должно появиться приглашение DSS.
UGPLAY сохраняет загруженный объект; его handle печатается при загрузке.
После проверки освободить именно этот handle: UGMEM FREE <handle>.

Дополнительно: UGPLAY FLT8.MOD /GS /VERIFY (GS повторяет песню), затем
UGPLAY STOP и UGMEM FREE <напечатанный EXT handle>. GS aliases для этого
пути не нужны. Для прерывания ожидания использовать ESC. Проверить сначала
с обычным Turbo ON, затем при необходимости повторить на другом слоте.
Сообщить команды, слот, слышимость обеих половин, переходы, EOF/ESC и возврат DSS.

Поддерживается PCM FLT8 с существующим native MOD-effects профилем ТЗ §10.3.
StarTrekker AM/FM companion files и macros не поддерживаются. Все128 order
bytes нормализуются через >>1; хвостовой FF требует pattern127. Неполные пары,
недостаточные samples, неверные instruments в используемых паттернах и неверные
loops отвергаются. Исходные байты
никогда не переписываются. CAPS.formats bit5 включён; protocol4/API1.0 прежние.

HOST включает production C/UBSan, независимый эквивалент8CHN, ошибки чтения,
actual EXE slots/IFF/Turbo/ESC/timeout/lost ACK/ownership, resident DSS RAM,
PAGE3/стек и linked Cortex-M0 parser/tracker/mixer с независимыми FX.
Эти проверки не являются физическим прослушиванием или замером ISA/render.
Оптимизация streaming S8c — следующий этап, известный REAL_FAIL не снят.

Дополнение: FLT4 и многоканальные MOD (1CHN..9CHN, 10CH..32CH).
FLT4 — обычные паттерны по1024 байта, orders не делятся на2. Применяется
существующий native MOD-effects профиль; AM/FM companion files/macros исключены.
CAPS.formats bit3 включает FLT4, bit6 обозначает MOD1..32; формат ответов прежний.
Общий пул —32 голоса: MOD28 оставляет4 для FX, MOD31 —1, MOD32 —0.
Недостаток свободных голосов возвращает NO_VOICE, музыка не обрезается.
GS63/64 по-прежнему показывают первые4 канала; SNAPSHOT/VOICE_STATUS — все.

    UGPLAY FLT4.MOD /WAIT
    UGPLAY MOD28.MOD /WAIT
    UGPLAY MOD31.MOD /WAIT
    UGPLAY MOD32.MOD /WAIT

FLT4.MOD: три паттерна, orders0,1,2,1,0,2, четыре разных инструмента/периода.
MOD28/31/32.MOD: два паттерна, разные инструменты/периоды, в том числе последние
каналы. После каждого запуска освободить напечатанный handle: UGMEM FREE <handle>.
Повторить через /GS /VERIFY, затем UGPLAY STOP и UGMEM FREE <handle>.

Оригинальный пользовательский DOPE.MOD (28CH) проверяется отдельно и в комплект
не включён. На Sprinter скопировать его со своего диска и выполнить:

    UGPLAY DOPE.MOD /WAIT /VERIFY
