CPU/NMI и границы доказательства
------------------------------
UG_CPU_PROFILE вызывается после смены режима CPU; automatic detection BIOS
не заявляется. Профили 21MHz/3.5MHz имеют разные chunks 32/8, unknown=8/FIXED.
Максимальное виртуальное открытое ISA-окно в 1024-byte тестах: ~985us @21MHz
и ~5909us @3.5MHz (snapshot). Это ниже модельного 10ms предела; цель 2ms и
физические wait states/IOCHRDY не подтверждены и остаются REAL S1/S5 gates.
NMI-safe FIXED/ALIAS проходят с обычным SP; STACK допускается только при
явно доказанном внешнем исключении NMI. Его hardware safety не подтверждена.
Maskable IRQs, полное BIOS/MMU paging, DSS disk services не моделируются.

Оставшиеся границы плана / scope
------------------------------
Минимальный UGDIAG не читает файлы и не имеет CLI arguments; file-error/ESC
матрица восьми будущих приложений не реализована в этом S0b harness и относится
к следующим этапам. Обязательный S0b минимальный вертикальный сценарий и
явный transfer cancel/timeout/commit failure покрыты; не выдаются за file I/O.
Публичные UG_WRITE/UG_READ сейчас BULK_FAST/BULK_VERIFIED; GS_FAST/GS_VERIFIED
отклоняются честно BAD_ARGUMENT. Slow GS transport тестируется в port model,
но его публичный ASM путь остаётся работой следующего host этапа.
Music parsers/engine/voice scheduler, production §13.2 bundle, восемь apps,
seven-mode firmware, MAME и REAL hardware gates S1–S11: PENDING.
Fixture checks подтверждают layout/content, не audio/parser functionality.
Подробный исполняемый отчёт не является доказательством всех возможных ветвей
будущего ABI и всех аппаратных конфигураций.

Находки и исправления
---------------------
R01 P1 — tests/ultrags/dss/run-ugdiag.mjs, loader tests.
The old loader accepted any exception as the expected defect; the over-C000
fixture was too short and failed the header size check. Exact diagnostic checks
and a correctly sized crossing image now exercise the intended refusal.

R02 P1 — host/sprinter/ultrags/lib/ugproto.asm, public ABI.
UG_FRAME_CRC(1), UG_SNAPSHOT and UG_GS_COMMAND could succeed with A != 0.
UG_XCTRL had the same issue. Success now returns CF=0/A=0; st-transfer checks
these entries, including a GS reply of 5Ah that must not leak into success A.

R03 P1 — ugproto.asm and apps/ugdiag.asm, recovery.
Best-effort CANCEL could overwrite the primary LAST_ERROR/SOURCE. Window-open
fail paths could close an already owned outer window. Error bookkeeping is
preserved across cancellation, cancellation failure has a control fallback,
and failed opens never close a window they did not acquire. Diagnostic cleanup
now cancels before FREE/printing; X_ERROR survives ISA_CLOSE register clobbers.
PSRAM commit failure is exercised by actual st-writefail machine bytes.

R04 P1 — ugproto.asm, READY/BEGIN/END validation.
RPC sent bytes without checking READY and could consume an old response as
its own. WRITE/READ used a malformed successful BEGIN payload as a token;
END accepted a nonempty successful payload. READY is now polled in bounded
windows, stale replies and frame faults reset transport without replaying RPC,
BEGIN lengths (4/8) and empty END are checked. st-pending and short-BEGIN
hardware injections exercise refusal/recovery and no data writes.
STACK's saved caller method uses separate scratch from X_CONTROL operands.

R05 P1 — ugproto.asm and ug-harness.mjs, CPU profiles and NMI.
There were no distinct CPU profiles: the report's no-turbo claim was based
on one chunk=32 at a hardcoded 21MHz. UG_CPU_PROFILE now selects turbo=32,
3.5MHz=8, unknown=8/FIXED, rejecting a profile change in an active transfer.
Harness time advances at the selected 21/3.5MHz rate. Actual 1024-byte writes
use 32 or 128 windows; reads also split. Ordinary-stack FIXED/ALIAS runs
receive 1024/128 real NMI injections and pass. A known policy that excludes
NMI tests STACK; unknown policy refuses STACK; the existing hazardous STACK
run still detects implicit NMI push corruption. Loop budget now has its own
infinite assembled EXE test with exact instruction count, PC and trace tail.
Positive tests reject unrelated violations and check final IFF/MMU/system/SP.
The workspace bound was corrected from BE20h to BD90h (BC00h+400).

R06 P1 — tools/ultrags/gen-fixtures.mjs.
M!K! was incorrectly encoded as eight channels. Positive FLT8 declared 64
sample bytes but supplied 32, its halves were identical, and pattern notes
referenced sample 0. Corrected to four-channel M!K!, distinct FLT8 halves,
sample 1 notes and complete sample area. Added the full RAW format/channel/
rate matrix, exact signed/unsigned endpoints, WAV rates/channel matrix and
valid/invalid loops. Independent test-fixtures checks lengths, sample areas,
loop bounds, endpoint values, headers and every byte/hash from two generations.

R07 P1 — tools/ultrags/build-evidence.mjs, assemble, runner, pack/verify.
Old package checks compared containers with files that happened to be present,
without binding them to current sources/schema or successful execution. The
old stale-EXE test merely compared two different executables. Content evidence
now covers all ASM/include sources, schema, generator and generated ASM,
assembler version, every built/executed EXE hash/set, harness/core/model/runner
inputs, fixture generator and packer. Package requires test-dss and rejects
stale/missing/failed execution. Actual verifier subprocess tests independently
mutate source, schema, generator, generated ASM, EXE, harness, execution data,
fixture generator, packer, ZIP and IMG; each requires its exact diagnostic.
A second real packer invocation proves ZIP/IMG/manifest determinism.

R08 P2 — package-s0b.mjs and verify-package.mjs, FAT12/ZIP structure.
FAT12 lacked 55AA boot signature and directory reserved bytes contained spaces;
reader ignored the second FAT and could accept damaged/cyclic chains. Corrected
BPB/signature/reserved fields; verifier checks both FATs, names, allocation,
chain length/termination/cycles/crosslinks. ZIP local/central metadata agree.
Embedded MANIFEST.TXT values (not just names) are verified. HELP accurately
states slot 0/base 02A0h/no arguments and flags defective selftests for harness
use. Native read-only fsck_msdos and Python zipfile independently accept artifacts.

R09 P1 — tools/ultrags/stage-excerpt.mjs.
Buffer identity comparison did not protect source aliases; duplicate headings
silently overwrote map entries, malformed tokens could disappear, and selecting
section 15 lost its stage bodies. inode checks protect symbolic/hard aliases;
duplicates and malformed/descending/missing references fail with diagnostics.
Complete hierarchical source spans are included once, including all of section
15 and unnumbered content. Fenced code is excluded from heading parsing.
All 14 stages, D01/D02, full-parent dedup and source preservation are tested.

R10 P2 — gen-wire.mjs, schema validation.
Input could supply generator-owned _size cache; non-ASCII byte constants and
nonboolean verifiedOnly were accepted, and variable-prefix declared size was
not checked. Reject these with named exact-diagnostic probes (34 total).

R11 P1 — ug-card.js, advertised scope.
PCM_CONFIG returned success after partial and incorrect descriptor validation
while CAPS advertised no playable formats. It now returns BAD_OPCODE explicitly
until the PCM milestone; a port-level test proves no fake musical success.

R12 P1 — ug-harness.mjs/run-ugdiag.mjs, ISA slots and EXE loading.
The card answered through either slot, masking slot selection defects. Routing
now selects the physical card slot; st-badslot requires slot 1 transactions and
wrongslot must fail honestly with no BASE accesses. The complete DSS file is
loaded at entry-header_size, including the consumed header, as in donor harnesses.

R13 P3 — Makefile.ultrags and reports.
Removed obsolete S0a comments claiming all S0b targets fail. check directly
requires test-dss, package requires tested bytes. Replaced historical acceptance
claims about profiles/freshness/fixtures with this review's actual evidence.
