------------------------------------

fixture generator и manifest; минимальный DSS EXE на sjasmplus;
actual-machine-byte harness и дефектные self-tests §14.1; профили
turbo/no-turbo; модель CB/DB с 7Eh; fault injection NMI с запретом STACK
при неизвестном NMI-контракте; stage-excerpt tool и self-tests §13.5;
без подмены EXE моделью алгоритма. Make targets: host-test, fixtures, dss,

Реализовано:

a) Wire schema → генерируемые константы (было в M1, оставлено)
   tools/ultrags/wire-schema.json + gen-wire.mjs ->
   build/ultrags/gen/ug_wire.inc + ug_wire.h + vectors-expected.h.
   Проверка: run-protocol-tests.mjs — 235 drift-субчеков схема↔вектора↔
   C↔ASM, 30 негативных проб схемы, 79 байт-сравнений на pinned Z80.

b) DSS-библиотека (host/sprinter/ultrags/):
   include/ugmem.inc — карта workspace; UGREQ.FRAME (140B scratch),
   UGREQ.ST (wire status сохраняется ДО копии payload — исправление
   aliasing-дефекта ниже), disjoint TOKEN/XFER поля, ASSERT границ.
   lib/isa.asm — ISA-8 окно: валидация слота 0/1 (2/3 отклоняются до
   любого обращения к шине), PAGE3/SYSTEM (readback, не каноническое 01h),
   PORT_ISA, IFF via LD A,I, WINDOW byte D4h+slot*2, без RESET-пульсов;
   ALIAS-окно и switched-STACK burst writers.
   lib/ugproto.asm — публичный ABI §12.1: каждый вызов сам открывает/
   закрывает короткое окно; UG_RPC (frame → X_REQUEST → bounded X_STATUS
   poll → response + trailer CRC); DE=response buffer, IX=capacity,
   exact-fit допустим, меньший размер → UG_ERR_OVERFLOW без копии и с
   TRANSPORT_RESET; UG_WAIT: REPLY проверяется до XERR, ошибочный ответ
   консумируется; статус возвращается CF=1/A=status через UGREQ.ST.
   UG_OPEN: сначала common-config (unlock CC→1D0, magic DD, protocol,
   FW_ACTIVE=E4=8, alias discovery) и только затем BASE/UltraGS
   регистры; UG_CURBASE хранит low byte базы. UG_WRITE/UG_READ: BEGIN →
   чанки (каждый собственное открытое/закрытое окно, ≤32B FIXED/ALIAS) →
   END, token сохраняется на всей передаче; VERIFIED добавляет host CRC
   в 13-байтный BEGIN и проверяет card CRC на READ; откат CANCEL при
   неудаче; UG_CLOSE отменяет живой grant. UG_METHOD_GATE: FIXED всегда,
   ALIAS при сконфигурированном окне, STACK только при UG_NMI_PROFILE=1,
   иначе UG_ERR_UNSAFE_NMI=0xF0 без касания шины (DI не маскирует NMI).
   UG_SNAPSHOT, UG_GS_COMMAND (дескриптор GS по §8), UG_FRAME_CRC.
   UG_WIN_OPEN — центральный session-gate: при UGCTX.SESS=0 возвращает
   CF=1/A=UG_ERR_STATE ДО любой записи в порты/ISA (исправление P1
   ревью ниже); все публичные ISA-пути (SNAPSHOT/XCTRL/GS_*/POLL_STATUS)
   проходят через него. Обе ошибочные ветки WIN_OPEN пишут публичный
   ABI-учёт UG_LAST_ERROR/UG_LAST_SOURCE через UG_SET_ERR (source HOST;
   см. находку №17). UG_OPEN намеренно использует UG_ISA_OPEN
   напрямую — common-config обязан идти до BASE-доступа.
   UG_ISA_CLOSE при ISOPEN=0 возвращает STATE без касания железа —
   fail-path после отказа no-session безопасен.
   UG_LAST_SOURCE: 0=NONE 1=HOST 2=X 3=GS; X резервируется за реальным
   wire status/X_ERROR карты, GS — за GS-latch таймауты; host
   transport/open/CRC/timeout — HOST. UG_FRAME_CRC принимает строго
   A∈{0,1}, прочее → BAD_ARGUMENT/HOST без изменения флага.
   lib/ugframe.asm, ugle.asm, ugcrc.asm — framing/LE/CRC32.

2. ИСПРАВЛЕННЫЕ ДЕФЕКТЫ ЭТОГО РАУНДА (намеренно пойманные)
--------------------------------------------------------

1. UG_RPC response-buffer aliasing (приоритетный баг ревью): payload
   LDIR в caller destination затирал wire status в FRAME[0], когда
   destination==UGREQ.FRAME — token low byte 1 читался как BAD_OPCODE.
   Статус теперь сохраняется в UGREQ.ST до копии. Покрыто st-respbuf
   (alias+distinct destination, nonzero payload byte, nonzero status,
   exact-fit vs OVERFLOW).
2. UG_XFER_END: stale flags после pop af → WRITE_END слался для READ
   (HANDLE). Исправлено: явный выбор opcode по DIR.
3. UG_OPEN: `ld b,1` затирал slot до .nosess-восстановления; UG_ISA_OPEN
   возвращал CF=0 при невалидном слоте. Ветка .slotok + scf.
4. UG_SNAPSHOT: UG_REG_R клобберил HL-указатель назначения (записи падали
   обратно в SNAP_DATA → BAD_REGISTER). Dest переведён в DE.
5. UG_WRITE_STACK: терял transport (A), длину (BC), и не давал
   корректный method switch; garbage UG_OFFSET в тесте. Полное сохранение
   аргументов + stash через UGREQ.GPRE; тест зануляет UG_OFFSET.
6. Response payload offsets после копии в caller буфер: token читается
   из FRAME+0/+2 (payload без заголовка), не из FRAME+2/+4.
7. UG_WAIT: проверка REPLY до XERR (оба бита могут быть подняты), wedged
   устранён; capacity проверяется до чтения payload; oversized/malformed
   ответ → TRANSPORT_RESET, noReply-ветка bounded (UG_WAIT_BUDGET=0x4000,
   ~1.57M инструкций ≲0.4с@21МГц).
8. UG_CURBASE: хранился slot вместо base low byte; diag проверяет
   CURBASE=0xA0 при slot=0 (разные значения).
9. ugmem.inc: UGREQ.TOKEN +38 пересекался с UGXFER.ID +40 → disjoint
   layout + ASSERT bound/overlap (проверено сборкой: нарушение ломает
   sjasmplus build).
10. Заголовок st-respbuf: второй ALLOC handle читался из UGREQ.FRAME
    после того как его перезаписал следующий RPC → дубль FREE → HANDLE.
    Handle фиксируется сразу после ответа.
11. st-nmihaz раньше проходил без доставленного NMI; теперь expectation
    требует nmiDelivered>=1 — поймано 64 доставки и порча данных.
12. Packer: DOS 8.3 имён >8 букв (ST-BADCRC и др.) молча обрезались —
    независимый верификатор поймал; deterministic ~N aliases + маппинг
    в manifest. Manifest list-check имел ошибочный slice (пропускал 2
    записи) — исправлено.
13. stage-excerpt: §9.2–9.3 терял хвост диапазона; §8.3.6 (пункт списка
    внутри §8.3) разрешается консервативным superset в §8.3; остаточные
    цифры после разбора = malformed error; overwrite источника запрещён;
    ENOENT на отсутствующий output dir устранён.
14. UG_WIN_OPEN без session-gate (P1 независимого ревью): публичные
    SNAPSHOT/XCTRL/GS_*/POLL_STATUS открывали окно на base 0000h после
    UG_LIB_INIT. Исправлено центрально: SESS=0 → CF=1/STATE до любого
    IO. UG_OPEN не затронут (использует UG_ISA_OPEN напрямую по
    контракту config-first).
15. Потеря ошибки через `pop af` в UG_XCTRL/UG_GS_SD/UG_GS_SC:
    fail-ветка восстанавливала caller AF поверх CF=1/A=err → ложный
    success при любом отказе окна. Поймано st-nosession на реальном
    EXE (XCTRL вернул CF=0). Исправлено: операнд хранится в
    UGREQ.GPRE, ошибка возвращается через `ret c` без восстановления
    AF. UG_SNAPSHOT использовал `pop hl` — корректен с самого начала.
16. Риски false-positive в runner-expectations (независимое ревью):
    st-nmihaz раньше принимал ЛЮБОЙ violation ИЛИ нечистый выход как
    доказательство NMI-опасности — посторонний harness-violation мог
    подменить именованный дефект. Теперь требуется строго:
    nmiDelivered>=1 (доставлено 64), exit=1, маркер E5h в result+3
    (тест пишет его только после повторной проверки порчи буфера) и
    НОЛЬ сторонних violations; число доставленных NMI печатается в
    detail каждого selftest-прогона. st-nmiunsafe раньше проверял
    только exit/err и uploaded=0 — отсутствие data-записей само по
    себе не доказывает отказ до шины. Теперь проверяется точный
    допустимый трейс: ровно 7 byte-writes в X_REQUEST (один кадр
    ALLOC op+len+5B), после последнего байта кадра только чтения,
    ноль обращений к BULK_DATA, после ПОСЛЕДНЕГО ISA-события в ioLog
    только close-restore PAGE3/SYSTEM (нет PORT_ISA-open, нет
    remap-значений), card.transfer===null, uploaded===0.
17. Публичный error-bookkeeping (независимое финальное ревью):
    а) новый session-gate UG_WIN_OPEN возвращал STATE напрямую, не
    записывая UG_LAST_ERROR/UG_LAST_SOURCE (ABI §12.1) — SNAPSHOT/
    XCTRL/GS_COMMAND отвечали верным кодом, но учёт оставался
    устаревшим. Ошибки UG_ISA_OPEN, пропущенные через WIN_OPEN,
    тоже терялись. Исправлено: обе ветки WIN_OPEN идут через
    UG_SET_ERR с source HOST.
    б) Владение источником: UG_RPC помечал X (b=2) host-side сбои —
    no-reply timeout, битый CRC принятого кадра, malformed length,
    неудачи poll/receive/xerr-окон. Все переведены на HOST; X
    оставлен за реальным wire status (.status) и X_ERROR-регистром
    (.xerr); GS-таймауты остаются GS.
    в) UG_FRAME_CRC принимал любое ненулевое A и отвечал success;
    теперь A∈{0,1} строго, прочее → BAD_ARGUMENT/HOST до записи
    флага. Покрыто новым st-framecrc (ноль IO за весь прогон);
    st-nosession проверяет учёт после каждого вызова; st-budget —
    TIMEOUT/HOST; st-badcrc — wire status CRC с source X.

4. CPU/NMI ДОПУЩЕНИЯ
--------------------

- Z80 ~21 МГц (Sprinter turbo); бюджет wait = 0x4000 итераций
  ≈1.57M инструкций ≈0.4с — консервативный верх; полл X_STATUS между
  опросами окно закрыто.
- NMI НЕ маскируется DI: harness доставляет NMI аппаратно (push PC,
  PC←0066h, IFF1←0) при обращении к отмеченному ISA-адресу. Политика
  UG_NMI_PROFILE: UNKNOWN(0) → UG_WRITE_STACK и METHOD:STACK отказываются
  с UNSAFE_NMI до касания шины; безопасность switched-SP окна при
  моделируемом NMI доказана только как демонстрация опасности
  (st-nmihaz ловит коррупцию), не как допуск — STACK остаётся refused by
  default. FIXED/ALIAS пути при обычном SP и смоделированном NMI
  проходят (st-alias, roundtrips).
- TURBO/NO-TURBO профили: фиксированные консервативные чанки ≤32B
  (ugproto UG_CHUNK=32), что подходит обоим профилям; отдельных бюджетов
  частоты нет — профили различаются только числом кадров ожидания.


5. SCOPE / ПРОПУЩЕНО
--------------------

- Music/audio-парсеры (MOD/FLT8/RAW decode, движок, I2S): fixtures
  являются ФОРМАТНЫМИ, функциональность не заявлена и не проверяется.
- UGCFG, восемь утилит, seven-mode multifw bundle: поздние этапы, в
  package не входят, HELP.TXT это декларирует.
- GS transports (01h/81h GS_FAST/GS_VERIFIED): не реализованы; public
  API отклоняет их BAD_ARGUMENT без обращения к шине (st-transport).
- STACK method: gated/refused при UNKNOWN NMI (см. §4); физическое
  доказательство безопасности отсутствует.
- MAME: ISA-модель не реализована — gate PENDING.
- REAL: плата/шина/IOCHRDY/PSRAM физически — PENDING (S1+).
- firmware/diagnostic/budgets (S0a make targets): PICO_SDK_PATH не
  установлен в этом окружении — не входили в прогон; host-test покрывает
  unit-уровень.


6. TESTER NOTES
----------------

- Один вход: `make -f Makefile.ultrags check` (или BUILD=… для
  изолированного дерева). Все подтесты итоговые строки печатают сами.
- Отсутствие self-test FAIL detection = сломанный harness: каждый
  дефектный selftest должен завершаться СВОИМ violation/ошибкой, не
  таймаутом и не исключением; см. ожидания в run-ugdiag.mjs SELFTESTS.
- Byte-identity: package собирает build/ultrags/dss/*.EXE; test-dss и
  вертикаль исполняют именно эти байты (--exe-dir); verify-package
  добывает их обратно из ZIP и IMG и сравнивает sha256.
- Свежесть: asm-manifest/package-manifest хранят sha256; подменённый
  EXE/битый ZIP/IMG детектируются (test-package.mjs, 8 кейсов in-memory,
  файлы не изменяются).
- Selftests оставляют свободный объект (objs=1) только там, где тест
  о взаимодействии violation+cancel; pin-release проверен в st-cancel
  (objs=0, transfer=null, cancel-фрейм на шине).
- Ошибки: wire status (A=status) vs host-private (UG_ERR_* ≥0xF0) vs
  card XERR vs harness violations — разные уровни, в логе разделены.
